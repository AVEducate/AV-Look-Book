Two minutes now saves a support email later. Everything below is a one-time thing.

Installing

Drag AV Look Book into Applications

Drop the app on the Applications folder shown in this window, then eject the disk image. Open it from Applications or Launchpad, not from the disk image.

First launch

“Apple could not verify AV Look Book is free of malware”

AV Look Book is not yet signed with an Apple Developer ID, so macOS stops the very first open. It is a one-time step:

  1. Click Done on that message.
  2. Open System Settings › Privacy & Security and scroll down to the Security section.
  3. Next to “AV Look Book was blocked” click Open Anyway, then confirm.

After that it opens like any other app.

“AV Look Book is damaged and can’t be opened”

This appears on older downloads, or when a copy has been passed between Macs. Open Terminal (Applications › Utilities), paste this one line, press return, then open the app again:

xattr -cr "/Applications/AV Look Book.app"

“The disk image is corrupted” or it won’t open

The download did not finish. The installer is about 100 MB; if the file in Downloads is smaller, delete it and download again from the releases page.

Your shows

Documents › AV Look Book

Every show is one .avlb file in that folder and is saved automatically while you work. Back the folder up like any other project folder, and copy a file to share a show with someone else.

The Welcome window lists your recent shows. Open Last Project takes you straight back to the one you were working on.

Updates

Automatic when online, silent when not

When your Mac is online, AV Look Book checks for a newer build on launch and every few hours. When one is ready you get an Update ready · Restart now note in the window. Offline it just runs.

New versions of the app shell itself are a fresh download from the releases page. The Welcome window shows which version you have.
